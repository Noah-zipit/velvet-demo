# VELVET — 3D Character Demo (18+)

A real-time 3D character showcase rendered with [Three.js](https://threejs.org/) and bundled with [Vite](https://vite.dev/).

- **Renderer:** antialias, soft shadows (`PCFSoftShadowMap`), ACES filmic tone mapping, pixel-ratio capped at 2.5
- **Scene:** fog-shrouded stage (`src/main.ts`), character rig in `src/dancer.ts`

## Run it

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs static files to dist/
```
